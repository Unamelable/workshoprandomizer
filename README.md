What randomizer can?
- Fully harvest workshop of the game to database (require [Steam Web API key](https://steamcommunity.com/dev/apikey), also account needs to be protected with steam guard to generate it.)
- Randomize by tags
- Open several window instances to randomize several items instead of one.
- Ignore already rolled items, and save them to seperate cache so it would not roll again.

I recommend you to save executable to seperate folder, since it gonna create 2 database files + App ID databases what ends with numbers.

Created with PySide6 & Python 3, and compiled by PyInstaller.
